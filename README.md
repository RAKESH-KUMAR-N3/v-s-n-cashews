# V S N CASHEWS

Premium Export-Grade Mangalore Cashew Nuts Wholesale & Retail Web Platform.

## Features
- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Motion
- **Backend**: Express.js, Better Auth Engine
- **Database**: MongoDB with Prisma ORM
- **Payments**: Razorpay Payment Gateway Integration
- **Features**: E-commerce store, B2B wholesale quotation system, GST invoicing, Admin Management Portal

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```
2. Configure `.env` using `.env.example` as reference with your MongoDB Atlas `DATABASE_URL`.
3. Run the app:
   ```bash
   npm run dev
   ```
